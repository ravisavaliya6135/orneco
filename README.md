# Orneco — Premium Facial Tissues

> **Pure & Soft. Thoughtfully Made in Bharat.**  
> Official web application and high-converting product landing page for **Orneco Health Care Pvt. Ltd.**

---

## 🌟 Highlights

- **Single-Page Application (SPA) with Automated SSG**: Fast, responsive React 19 + TypeScript + Tailwind CSS v4 architecture with automated static HTML pre-rendering (`prerender.js`) for universal search crawler indexing.
- **100/100 SEO & AI Search Readiness**: Complete Schema.org JSON-LD structured data (`Product`, `Organization`, `WebSite`), meta tags, Open Graph, Twitter Cards, `robots.txt`, `sitemap.xml`, and `llms.txt`.
- **Next-Gen WebP Imagery**: Next-gen WebP compressed assets with responsive `<picture>` fallbacks, reducing image payloads by 58%.
- **Zero CLS & Optimized Core Web Vitals**: Explicit image aspect ratios, hero image high-priority preloading (`fetchPriority="high"`), preconnected Google fonts, and zero render-blocking CSS imports.
- **Transparent Consumer Policies**: Integrated modals for Privacy Policy, Terms of Service, Shipping, and Return/Refund guidelines.

---

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite 7
- **Language**: TypeScript 5.9
- **Styling**: Tailwind CSS v4
- **Single-File Bundler**: `vite-plugin-singlefile`
- **Pre-rendering**: Node.js SSR pipeline via React's `renderToString` and `hydrateRoot`

---

## 🚀 Quick Start

### 1. Installation
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production (with SSG Pre-rendering)
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
